# Iris Flower Classification

## Project Overview
This project classifies Iris flowers into three species:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code

## Machine Learning Algorithm
K-Nearest Neighbors (KNN)

## Dataset
The dataset contains 150 samples and 6 columns:
- Id
- SepalLengthCm
- SepalWidthCm
- PetalLengthCm
- PetalWidthCm
- Species

## Model Accuracy
Accuracy Obtained: 100%

- Iris.csv

## Conclusion

The Iris Flower Classification model was successfully developed using the K-Nearest Neighbors algorithm and achieved excellent accuracy.
