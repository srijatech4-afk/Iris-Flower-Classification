# Iris Flower Classification using Machine Learning

## Project Overview

This project aims to classify Iris flower species using the K-Nearest Neighbors (KNN) algorithm. The Iris dataset contains measurements of sepal length, sepal width, petal length, and petal width to predict the flower species.

## Dataset

The dataset contains 150 samples of Iris flowers belonging to three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* VS Code

## Exploratory Data Analysis (EDA)

Data visualization techniques were used to understand the dataset:

* Count Plot
* Pair Plot
* Correlation Heatmap

## Machine Learning Model

Algorithm used:

* K-Nearest Neighbors (KNN)

## Model Evaluation

The model was evaluated using:

* Confusion Matrix
* Classification Report
* Accuracy Score

### Accuracy Achieved

The K-Nearest Neighbors (KNN) model achieved an accuracy of **100%** on the test dataset.
